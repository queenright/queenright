# Queenright

Stable concepts for human–agent collaboration: identity, ownership, access and
interaction rules for agent teams, independent of any tool.

*Queenright* is a beekeeping term for a colony with a functioning queen:
complete, in order, working. The opposite is *queenless*. This project asks the
same question of a team of people and agents: **is it queenright?**

This is a blueprint, not a product. It holds concepts, a policy schema and
mappings to concrete platforms. It holds no runtime and no hosting code.
