# Queenright

Stable concepts for human–agent collaboration: identity, ownership, access and
interaction rules for agent teams, independent of any tool.

**AI agents are joining the workforce. Most are still set up like tools, though they work like colleagues.**

| As-is | Should-be |
|---|---|
| Everyone brings their own agents | Agents are brought into the team |
| Agents act under a person's login | Agents operate under their own identity |
| Rules are a line in the prompt | Rules are enforced outside the agent |
| Nobody answers for an agent | Every agent has an accountable owner |
| Agents are tools | **Agents are collaborators** |

*Queenright* is a beekeeping term for a colony with a functioning queen:
complete, in order, working. The opposite is *queenless*. This project asks the
same question of a team of people and agents: **is it queenright?**

It holds concepts you can apply today, on any platform. Where it goes
from here, practice will show.
